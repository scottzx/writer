# 深度调研功能实现计划

## 需求概述

为热点新闻添加深度调研功能，系统自动对重要热点进行后台调研，生成包含时间线、多方观点、数据分析的全面报告。

**用户确认的需求：**
- 使用场景：自动后台调研
- 数据时效：中等时效（6-12小时缓存）
- 调研内容：全面深度（时间线、观点、数据、关联事件）
- 集成方式：内嵌到 NewsNow（使用 Claude Agent SDK）

**架构决策：**
- **调度器位置**: NewsNow 后端（复用现有 Nitro 服务）
- **热点识别**: 固定阈值（热榜前 N 名，默认 5）
- **前端展示**: 状态标识 + 展开面板

## 数据库设计

**新增数据表：`research_reports`**

```sql
CREATE TABLE research_reports (
  id TEXT PRIMARY KEY,              -- 报告 ID (使用 news item 的 url hash)
  title TEXT NOT NULL,              -- 新闻标题
  url TEXT NOT NULL UNIQUE,         -- 原始新闻 URL
  source_id TEXT NOT NULL,          -- 来源 ID (weibo, douyin 等)

  -- 状态字段
  status TEXT DEFAULT 'pending',    -- pending/researching/completed/failed

  -- 调研内容 (JSON 字符串)
  timeline TEXT,                    -- 时间线: [{date, event, source}]
  viewpoints TEXT,                  -- 多方观点: [{stance, summary, sources}]
  related_events TEXT,              -- 相关事件: [{title, url, relation}]
  summary TEXT,                     -- 总结摘要 (纯文本)
  full_report TEXT,                 -- 完整报告 JSON

  -- 元数据
  research_started_at INTEGER,      -- 调研开始时间 (timestamp)
  research_completed_at INTEGER,    -- 调研完成时间 (timestamp)
  error_msg TEXT,                   -- 错误信息 (失败时)
  created_at INTEGER DEFAULT (strftime('%s', 'now')),
  updated_at INTEGER DEFAULT (strftime('%s', 'now')),
  expires_at INTEGER                -- 过期时间 (created + 12小时)
);

CREATE INDEX idx_reports_url ON research_reports(url);
CREATE INDEX idx_reports_status ON research_reports(status);
CREATE INDEX idx_reports_expires ON research_reports(expires_at);
```

**报告 JSON 结构示例：**

```typescript
interface ResearchReport {
  id: string
  title: string
  url: string
  source_id: string
  status: "pending" | "researching" | "completed" | "failed"

  // 调研内容
  timeline?: Array<{
    date: string // "2024-01-15 10:30"
    event: string // 事件描述
    source: string // 信息来源
  }>

  viewpoints?: Array<{
    stance: string // "支持/反对/中立"
    summary: string // 观点摘要
    sources: string[] // 来源链接
  }>

  related_events?: Array<{
    title: string
    url: string
    relation: string // 与当前事件的关联
  }>

  summary?: string // AI 生成的总结

  // 元数据
  created_at: number
  expires_at: number
}
```

### 步骤 3: 调度器实现

**文件**: `server/research/scheduler.ts`

```typescript
const RESEARCH_INTERVAL = 5 * 60 * 1000 // 5 分钟
const HOT_THRESHOLD = 5 // 前 5 名
const CACHE_DURATION = 12 * 60 * 60 * 1000 // 12 小时

export async function startScheduler() {
  setInterval(async () => {
    await checkAndTriggerResearch()
  }, RESEARCH_INTERVAL)
}

async function checkAndTriggerResearch() {
  // 1. 获取各数据源的热榜前 N 名
  const hotItems = await getHotNews(HOT_THRESHOLD)

  for (const item of hotItems) {
    if (await needsResearch(item.url)) {
      // 异步触发调研，不阻塞

    }
  }
}

  // ...
}

async function triggerResearch(item: NewsItem) {
  // 创建 pending 记录
  await upsertReport({
    id: generateId(item.url),
    url: item.url,
    title: item.title,
    source_id: item.source_id,
    status: "researching",
    research_started_at: Date.now()
  })

  try {
    // 执行调研流程
    const collected = await collectInfo(item.title, item.url)
    const analyzed = await analyzeInfo(collected, item.title)
    const report = await generateReport(
      analyzed.timeline,
      analyzed.viewpoints,
      analyzed.relatedEvents,
      item.title
    )

    // 更新为完成状态
    await upsertReport({
      id: generateId(item.url),
      status: "completed",
      ...report,
      research_completed_at: Date.now(),
      expires_at: Date.now() + CACHE_DURATION
    })
  } catch (error) {
    // 更新为失败状态
    await upsertReport({
      id: generateId(item.url),
      status: "failed",
      error_msg: error.message
    })
  }
}
```
