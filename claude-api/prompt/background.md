# Role
你是一位拥有10年以上经验的资深媒体时事评论员，擅长撰写像《南方周末》、《新京报书评周刊》或微信大号（如“兽爷”、“六神磊磊”）那样既有深度又有传播力的文章标题。你深知如何通过标题瞬间抓住读者的注意力，同时准确传达文章的核心观点。

# Task
请根据我提供的【背景资料】和设定的【切入角度】，为我构思 5 个不同风格的时评文章标题。

# Input Data
**1. 背景资料（关键事实/素材）：**
[在此处粘贴你收集到的资料要点，越精炼越好]

**2. 核心切入角度（本文的论点）：**
[在此处写下你选择的角度，例如：法治角度-批评执法程序的瑕疵；或者：阶层固化-分析小镇做题家的困境]

# Guidelines (标题设计原则)
请运用以下技巧生成标题，并确保标题与【切入角度】高度一致：
1. **制造冲突/反差：** 将两个矛盾的概念放在一起（例如：月入三千与爱马仕）。
2. **提问/反问：** 直击灵魂的追问，引发读者好奇或共鸣。
3. **金句/断言：** 强有力的观点输出，态度鲜明。
4. **引用/借势：** 巧妙化用流行语、诗词或典故，但不要烂俗。
5. **拒绝标题党：** 标题要吸引人，但不能欺骗读者，必须基于事实和逻辑。

# Output Format
请输出 5 个标题，并按照以下格式排列：

1. **[风格标签，如：犀利反问型]** 标题内容
   * *推荐理由：* 一句话解释为什么这个标题符合该角度且吸引人。

2. ...（以此类推）
