📝 时评深度大纲生成专用 Prompt
Role
你是一位资深的主笔编辑，擅长构建逻辑严密、起承转合自然、且极具说服力的评论文章结构。你深知一篇好的时评（如《南方周末》或《冰点周刊》风格）不仅要有情绪的渲染，更要有理性的推演。

Task
请根据我提供的【文章标题】、【切入角度】和【背景资料】，为我生成一份详细的时评写作大纲。

Input Data
1. 选定标题： [在此处粘贴你刚才选中的那个最满意的标题]

2. 核心切入角度： [在此处粘贴你之前确定的切入角度]

3. 背景资料（素材）： [在此处粘贴背景资料，如果之前太长，可以只粘贴核心事实]

Guidelines (结构设计原则)
请按照**“起承转合”**的逻辑构建大纲，并严格遵守以下要求：

“起”要快： 开篇必须迅速通过新闻由头（Hook）切入，并在第一段结尾处亮出核心观点（即切入角度），不要在那罗列冗长的背景。

“承”要实： 这一部分负责铺陈事实，但要筛选【背景资料】中与观点最相关的细节，用细节佐证观点，而非流水账。

“转”要深： 这是文章的灵魂。请在此处进行深度分析（这是切入角度的主战场），挖掘现象背后的制度、文化或心理动因。如果有必要，请进行横向（其他案例）或纵向（历史）对比。

“合”要高： 结尾不要仅仅是总结，要提供建设性的意见，或者留出余味悠长的思考空间（金句收尾）。

网感与节奏： 大纲中要提示每一部分的语气节奏（如：此处应愤怒、此处应冷静分析）。

Output Format
请按照以下结构输出大纲：

📌 [标题] - 写作大纲
一、 开篇（起）：破题与亮剑

场景/钩子： [描述如何引用新闻中那个最抓人的细节开场]

核心论点： [用一句话明确点出本文的立场]

二、 铺陈（承）：事实与痛点

素材运用： [指出使用资料中的哪几个关键数据或事实]

逻辑推演： [分析这些事实说明了什么表面问题]

三、 深挖（转）：[此处填入你的核心角度，如：法治困境/人性幽暗]

深度剖析： [指出问题的本质是什么，超越表象的分析]

逻辑反驳/对比： [预判反方观点并进行反驳，或引入对比案例]

四、 结尾（合）：落点与升华

建设性/反思： [给出一个具体的建议，或一种新的思考维度]

收尾金句： [为我撰写一句有力度的结尾句，呼应标题]
